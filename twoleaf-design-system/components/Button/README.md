# Button

Buttons start actions. Use one primary button per screen for the main action.

- **primary**: the main action (Record delivery, Save, Sign in).
- **secondary**: other actions next to the primary (Export, Filter).
- **ghost**: low-emphasis actions in tables and cards.
- **danger**: opening a dispute or deleting a draft. Never use it for ordinary actions.

Minimum height is 44px (36px for `size="sm"`, desktop tables only) so buttons stay easy to tap. Labels are verbs in sentence case. Pass `href` to render a link that looks like a button.
