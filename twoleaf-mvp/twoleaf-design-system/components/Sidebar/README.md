# Sidebar

The left drawer of the factory and county web apps.

**This is the only place a factory's own branding appears.** A factory sets `logoUrl` and `orgName`; everything else (colours, fonts, layout) stays TwoLeaf. Without a logo the drawer shows the name's initials. The bottom always carries the theme toggle and the *Powered by Mariakani Labs* credit, which tenants cannot remove. On screens under 900px it becomes an overlay drawer opened from a menu button.
