# Badge

Badges show the status of a record in a word or two.

| Tone | Use for |
|---|---|
| success | Paid, approved, quality on target |
| warning | Pending, syncing, below target |
| danger | Disputed, rejected, error |
| info | Offline, informational |
| neutral | Draft, archived |

The dot plus the word carries the meaning, so status never depends on colour alone.
